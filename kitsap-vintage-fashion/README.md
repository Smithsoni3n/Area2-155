# Kitsap Vintage Fashion 1960s–70s

This is a standalone static website folder.

## Preview options

1. **Open directly as a static file**
   - Open `kitsap-vintage-fashion/index.html` in your web browser.

2. **Use VS Code Live Server**
   - Open the repository in VS Code.
   - Right-click `kitsap-vintage-fashion/index.html`.
   - Choose **Open with Live Server**.

## Notes

- The slideshow image paths use relative links (`assets/item1-01.jpg`, etc.) so they work when opened directly from file.
