# ⬡ THERMAL VISION — Color Intelligence System

A typography and color psychology academic project exploring how thermal infrared color mapping relates to human psychological responses.

## Project Structure

```
/ (repo root)
├── index.html                        ← Homepage — drop this at root
└── thermal-vision/
    ├── hot-colors.html               ← Red / Orange / Pink psychology
    ├── cold-colors.html              ← Blue / Cyan / Violet psychology  
    ├── interactive.html              ← Live temperature slider + Chart.js
    └── resources.html                ← Academic citations + Swiper gallery
```

## GitHub Pages Deployment

1. Drag **all contents** of this folder into your GitHub repository root
2. Make sure `index.html` is at root and `thermal-vision/` folder contains the 4 sub-pages
3. Go to: **GitHub Repo → Settings → Pages → Source: Deploy from branch → Branch: main → Folder: / (root) → Save**
4. Your live site: `https://[username].github.io/[repo-name]/`

## Tech Stack

| Tool | Purpose |
|------|---------|
| **Orbitron** | Display / heading typography |
| **Exo 2** | Body copy typography |
| **Tailwind CSS v4** | Utility-first styling via CDN |
| **GSAP 3.12 + ScrollTrigger** | Animations & scroll reveals |
| **Alpine.js v3** | Reactive interactive scanner |
| **Chart.js v4** | Arousal curve visualization |
| **Swiper v11** | Spectrum gallery carousel |
| **tsParticles v2** | Particle system overlay |

## Academic References

All psychological claims are backed by peer-reviewed research. See `resources.html` for full citations with links to original sources including Elliot & Maier (2007), Mehta & Zhu (2009), Hill & Barton (2005), Russell (1980), Schauss (1979), and more.
