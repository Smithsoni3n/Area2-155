# Thermal Vision (Typography Project)

Standalone website folder for GitHub upload and GitHub Pages deployment.

## Files
- `index.html` — Hero landing + intro + nav cards.
- `hot-colors.html` — Hot thermal color psychology.
- `cold-colors.html` — Cold thermal color psychology.
- `interactive.html` — Slider + arousal chart interactive lab.
- `resources.html` — Academic links + media gallery + stack.
- `assets/css/styles.css` — Shared futuristic visual system.
- `assets/js/main.js` — Shared motion + Color Intelligence renderer.

## Run locally
From this folder:

```bash
python3 -m http.server 5500
```

Then open `http://127.0.0.1:5500/index.html`.

## Publish on GitHub Pages
Upload the full `thermal-vision/` folder to your repository root or set Pages to this directory.
