# Thermal Vision Website

Upload the entire `thermal-vision/` folder to your GitHub repository to publish as a static site.

## Pages
- `index.html` – homepage with thermal scan hero and navigation cards
- `hot-colors.html` – hot color psychology research
- `cold-colors.html` – cold color psychology research
- `interactive.html` – Alpine + Chart.js interactive model
- `resources.html` – references and Swiper gallery

## Shared files
- `styles.css` – futuristic thermal design system
- `main.js` – GSAP/Anime particle effects, chart bootstrap, swiper setup
