Part I — Questions I Through X
Question I
Write a regular expression that finds three digits, followed by a dash, followed by three digits, followed by a dash, followed by four digits (an American phone number).
Answer →\d{3}-\d{3}-\d{4}
Question II
Write a regular expression that finds all instances of the separate word "color".
Answer →\bcolor\b
Question III
Write a regular expression that finds all instances of the array of characters "colour" even when it is a substring inside of a larger string.
Answer →colour
Question IV
Write a regular expression that finds all instances of "car" when it appears as a separate word, but does NOT find "car" when it is inside another word such as "carnival" or "caricature".
Answer →\bcar\b
Question V
Write a regular expression that finds all instances of "Car" (with the capital letter C) when it appears as the first word on a line.
Answer →^Car
Question VI
Write a regular expression that finds all instances of "car" (with the lower-case letter c) when it appears as the last word on a line.
Answer →car$
Question VII
Write a regular expression that finds all instances of the string "zz" such as in the word pizzazz.
Answer →zz
Question VIII
Write a regular expression that finds all instances of the binary number "1101" when it appears as a separate array of characters or as a substring within another larger array of characters.
Answer →1101
Question IX
Write a regular expression that finds all instances of the binary number "1101" but only when it appears as a separate array of characters (not as a substring).
Answer →\b1101\b
Question X
Write a regular expression that finds all instances of the array of characters "CaMelcaSE" even when it is a substring of a longer array of characters.
Answer →CaMelcaSE
Part II — Questions XI Through XXV
Question XI
Write a regular expression that finds all strings that consist of two NON-digit characters that are right next to each other.
Answer →\D\D
Question XII
Write a regular expression that finds all individual word characters in a given sample of text.
Answer →\w
Question XIII
Write a regular expression that finds all individual non-word characters in a given sample of text.
Answer →\W
Question XIV
Write a regular expression that finds all individual non-space characters in a given sample of text.
Answer →\S
Question XV
Write a regular expression that finds all individual space characters in a given sample of text.
Answer →\s
Question XVI
Write a regular expression that matches the word cat, in lower-case, but only when the letters are separated by a single space (e.g. c a t). This array of characters should not be a substring of another larger array of characters.
Answer →\bc a t\b
Question XVII
Write a regular expression that matches prices in the following format: a dollar sign, followed by the number 9, followed by any other single number, followed by a single period character, followed by any two numbers (e.g. $94.12, $90.20, $99.99).
Answer →\$9\d\.\d{2}
Question XVIII
Write a regular expression that matches three numbers followed by three letters followed by three numbers, even when such an array of characters is a substring of another array of characters.
Answer →\d{3}[a-zA-Z]{3}\d{3}
Question XIX
Write a regular expression that matches the phrase "Nota Bene" but only when the two words appear adjacent to each other. This should be a case-sensitive search.
Answer →Nota Bene
Question XX
Write a regular expression that matches the period character, but only when it appears as the last character on the line.
Answer →\.$
Question XXI
Write a regular expression that will find all individual characters of any type, except line-ending types of characters (e.g. newline character).
Answer →.
Question XXII
Write a regular expression that will find the word "The" only when it appears as the first word on a line.
Answer →^The\b
Question XXIII
Write a regular expression that will find the word "end" only when it appears as the last word on a line.
Answer →\bend$
Question XXIV
Write a regular expression that will find all strings of characters that start with the lowercase letter "h", followed by a single character, and ending with the lower-case letter "t" (e.g. hat, hot, hit) — including substrings.
Answer →h.t
Question XXV
Write a regular expression that will only find whole words that start with the lower-case letter "h", followed by a single character, and ending with the lower-case letter "t" (e.g. hat, hot, hit).
Answer →\bh.t\b

Six Principles of Pattern Logic
I. Anchors Govern Position, Not Content
^ and $ do not match characters — they match positions. ^ means "the position at the start of a line." $ means "the position at the end of a line." They anchor your pattern to a specific location in the text.
II. Word Boundaries Are Invisible Walls
\b matches the invisible boundary between a word character and a non-word character. Placing \b on both sides of a pattern (e.g. \bcar\b) ensures the entire match is a standalone word. Without \b, your pattern will match inside longer words.
III. Special Characters Must Be Escaped
Several characters have special meaning in regex: . $ ^ \ ( ) [ ] { } + * ?. To match any of these literally, place a backslash before them. For example, \. matches an actual period, and \$ matches an actual dollar sign.
IV. Quantifiers Control Repetition
{n} means exactly n times. {n,m} means between n and m times. + means one or more. * means zero or more. ? means zero or one. A quantifier always applies to the token immediately preceding it — for example, \d{3} means exactly three digits.
V. Character Classes Define a Set of Choices
Square brackets define a set: [abc] matches "a", "b", or "c". A hyphen inside brackets defines a range: [a-z] matches any lowercase letter. [a-zA-Z] matches any letter of either case. A caret inside brackets negates the set: [^0-9] means any character that is NOT a digit — equivalent to \D.
VI. Regex Is Case-Sensitive by Default
"Car" and "car" are treated as entirely different patterns. The pattern ^Car will not match a line beginning with "car". To make a pattern case-insensitive, use the /i flag in JavaScript, the (?i) modifier in Python, or the equivalent in your language of choice.

XI\D\D\D matches any single non-digit. Two \D side by side requires two consecutive non-digit characters next to each other.
XII\w\w matches every individual word character — letters a–z, A–Z, digits 0–9, and underscore. Each one is matched separately.
XIII\W\W is the inverse of \w. It matches every character that is not a letter, digit, or underscore — spaces, punctuation, symbols.
XIV\S\S matches every non-whitespace character individually. Every visible character qualifies; spaces and tabs do not.
XV\s\s matches each whitespace character — the space, tab (\t), newline (\n), and carriage return (\r).

XVII\$9\d\.\d{2}\$ matches a literal dollar sign. 9 is literal. \d is any digit. \. is a literal period. \d{2} requires exactly two digits at the end.
XVIII\d{3}[a-zA-Z]{3}\d{3}\d{3} requires 3 digits. [a-zA-Z]{3} requires 3 letters of any case. \d{3} requires 3 more digits. No boundaries — substring match is allowed.
XIXNota BeneA case-sensitive literal string. The single space between the two words requires them to be directly adjacent with no other characters between them.
XX\.$\. matches a literal period (without the backslash, . is a wildcard). $ anchors it to the end of the line.
XXI.The dot metacharacter matches any single character except newline by default. This is the universal wildcard in regular expressions.
XXII^The\b^ anchors to line start. \b ensures "The" is a complete word — "There" and "Their" are excluded because the word boundary fails after "The".
XXIII\bend$\b ensures "end" is a complete word, excluding "blend" or "fend". $ anchors the match to the very end of the line.
