v1.0 • Playful API Spec

Better Conversations API

A neutral, tongue-in-cheek REST API for people who talk, listen, and sometimes forget which one they’re supposed to be doing.

Base URL: https://api.conversations.local/v1 No politics. Just vibes.

Usage

Chain polite requests. Avoid unauthorized /interrupt calls. Rate limits reset after a deep breath.

Solo deck

Flip, try, reflect

The Better Conversations API deck is a one-player practice game. Each card is a conversational skill written like an API endpoint: flip a prompt, try it in your next interaction, and reflect on the “response” you get. There’s no competition—just a playful way to level up listening, empathy, and trust-building one card at a time.

The deck lives right here—no separate site or download. Scroll, pick an endpoint, and treat it like a mentor whispering in your ear as you talk.

“Nothing I say this day will teach me anything. So if I’m going to learn, I must do it by listening.”

Larry King

How it works

One-player practice deck

The deck is your personal sandbox: flip a card, try that conversational skill in your next chat, and notice the “response” you get back. No competition—just a playful way to level up listening, empathy, and trust one call at a time.

Step 1

Pick a card and commit to that endpoint for your next interaction.

Step 2

Ship the request in real life—/listen, /validate, or /keepConversationGoing.

Step 3

Log the “response”: what changed in tone, trust, or talk-time balance?

Step 4

Repeat with a new card to build uptime for empathy and curiosity.

Bonus mentor cards

TED-inspired side quests

Along the way you’ll encounter bonus cards inspired by TED speakers and thought leaders: Jia Jiang’s courage in “100 Days of Rejection,” Celeste Headlee’s “10 Ways to Have a Better Conversation,” Simon Sinek’s listening insights, and Larry King’s daily reminder to learn by listening.

GET

/listen

Activates listening mode and echoes what was actually said instead of what you assumed.

{
  "status": "listening",
  "filters": ["no multitasking", "no rehearsing comebacks"],
  "payload": "full human sentence received"
}
POST

/elevatorPitch

Uploads a short intro so everyone knows why you’re here.

{
  "name": "Your Name",
  "project": "What you're working on",
  "duration": "15 seconds"
}
Response: {"message": "Pitch accepted. Conversation initiated."}
PATCH

/keepConversationGoing

Keeps the flow alive so the chat doesn’t die 14 seconds in.

{
  "questions": "open-ended",
  "validated": true
}
Response flow: {"flow": "smooth", "awkwardSilence": false}
PUT

/activeListening

Engages real listening protocols. Fake nodding is rejected with a 409.

  • Paraphrase and confirm
  • Ask follow-up questions
  • Notice tone and cadence
  • Don’t hijack with your own story
POST

/emptyTheBucket

Lets someone empty their thoughts without interruptions.

{
  "bucket": "empty",
  "listener": "quiet",
  "speaker": "heard"
}
GET

/conversationHealth

Returns diagnostics so you know if the chat needs a reboot.

{
  "eyeContact": "fair",
  "engagementLevel": 82,
  "talkTimeBalance": "56% them / 44% you",
  "interruptions": 0,
  "empathy": "operational"
}
DELETE

/assumptions

Clears cached biases so you can listen like a human.

Response: {"message": "Assumptions successfully deleted.", "biasCache": "cleared"}
POST

/trust

Trust is earned through repeated /listen calls plus consistent behavior.

Response: {"trust": "building", "note": "Trust requires uptime, not just bandwidth."}
GET

/awkwardSilence

Returns a reflective pause to let ideas catch up.

{
  "duration": "3-7 seconds",
  "status": "productive",
  "tip": "Hold steady. Someone’s brain is buffering."
}

Pro Tips

How to avoid a 4XX Conversation Error

  • Pair /listen with /validate before any /interrupt attempts.
  • Throttle yourself to 120 words per minute to prevent rate limiting.
  • Use /keepConversationGoing if silence lasts longer than your comfort zone.
  • Call /assumptions daily for best performance.

Error Codes

  • 409 Topic collision — you hijacked their story.
  • 429 Too many words — slow your roll.
  • 451 Content unavailable — maybe this isn’t the time.
  • 520 Uncaught sarcasm exception — request clarification.
