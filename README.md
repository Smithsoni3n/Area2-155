The BetterConversationsAPI layout ships as a compact mountable block (about 5×7) with a GitHub shortcut so it can sit on a discussion board without a full-page backdrop.

**Embed endpoint (no extra assets):**

```html
<iframe src="https://smithsoni3n.github.io/Area2-155/BetterConversationsAPI/" title="Better Conversations API deck" width="420" height="340" style="border:0;border-radius:18px;overflow:hidden;background:transparent;"></iframe>
```

Paste that iframe directly into your discussion board to render the live study cards without showing a separate link.

**Do I need separate CSS or JS files?** No—everything is bundled inside `index.html`. Open it directly or serve the folder, and the deck loads with its colors and interactions without any extra assets.

**Local preview tip:** Run `python -m http.server 8080` **from inside** the `BetterConversationsAPI` folder and open `http://localhost:8080/` to see only the deck block (no surrounding site). Hard-refresh if you were serving a different folder.

## FAQ

**What is the server ID for the Python link?**

There isn’t a Python server ID because the BetterConversationsAPI deck is served as a static page on GitHub Pages. Use the live links above (for example, `https://smithsoni3n.github.io/Area2-155/BetterConversationsAPI/`) to view or share the deck without running any local Python server.
