About this project

Design for kids + elders

This site uses large tap targets, clear labels, readable contrast, and plain language. Interactive controls support keyboard use, visible focus outlines, and reduced-motion preferences.

Accessibility features included

  • Semantic landmarks and heading structure
  • Keyboard-friendly navigation, filters, slideshow, and builder controls
  • Text size and high-contrast toggles saved in localStorage
  • ARIA labels for slideshow controls and live status updates for the builder

Credits workflow

Use IMAGE_SOURCES.md to find and download approved historical media. Then fill in CREDITS.md with final credits and license details.
