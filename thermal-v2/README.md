# thermal-v2

Standalone multi-page **Thermal Vision** typography project.

## Files
- `index.html`
- `hot-colors.html`
- `cold-colors.html`
- `interactive.html`
- `resources.html`
- `styles.css`
- `main.js`

## Deploy quickly (GitHub Pages)
1. Upload the full `thermal-v2/` folder to your repo.
2. Keep these files together in the same folder.
3. Open `thermal-v2/index.html` as the homepage path.

## Notes
- Uses CDN libraries: Tailwind, GSAP, Anime.js, particles.js, Alpine.js, Chart.js, Swiper.
- Includes a Gorilla Live Area link on `resources.html`.
